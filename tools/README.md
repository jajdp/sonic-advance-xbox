# tools/

*(Español: [README.es.md](README.es.md))*

| | |
|---|---|
| `construir_uwp.py` | Builds the game with the UWP layer added |
| `empaquetar_sa2.py` | Packages and signs; the certificate thumbprint is a parameter |
| `construir-uwp.bat` | The same build from a plain `cmd` window, for when that is easier |

Every path is a parameter: there is no default pointing at the machine these were written on. Plain
Python 3, standard library only.
